- **Framework & Entry**: Built on Expo SDK 54 with a standard React Native entry point (`App.tsx`) wrapping the app in `GestureHandlerRootView`, `SafeAreaProvider`, and custom `ThemeProvider`.
- **Navigation Architecture**: Uses `@react-navigation` with a conditional root switch between `AuthNavigator` (login/onboarding) and `MainTabs` (authenticated). The main interface is a bottom-tab navigator containing nested native stack navigators for distinct domains: Dashboard, Core Chat, Thought Capture, Circle (Social), and More (Settings/Tools).
- **State Management**: Employs `zustand` for global client-side state, separated into domain-specific stores (`authStore`, `messagingStore`, `personaStore`, etc.). Stores handle persistence via `expo-secure-store` (tokens) and `@react-native-async-storage/async-storage` (user data/preferences), often implementing stale-while-revalidate caching patterns for dashboard data.
- **Data Layer**: A modular API client (`src/api/`) built on `axios` handles RESTful interactions with automatic JWT injection and 401-driven logout. Real-time features (chat, mediator streams) are managed via a singleton `socket.io-client` instance (`src/api/socket.ts`).
- **Theming & Styling**: Implements a dual-mode (light/dark) theme system via React Context (`ThemeContext`), consuming design tokens from `src/constants/colors`. Styling combines `StyleSheet.create` with `nativewind` (Tailwind CSS) utilities and custom neon-effect helpers.
